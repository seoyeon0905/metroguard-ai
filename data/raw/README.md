이 폴더는 원본 데이터 목록과 설명을 정리하는 공간입니다.  
실제 CSV 파일은 용량 및 데이터 공개 범위 문제로 GitHub에 업로드하지 않고, Google Drive에 별도로 보관합니다.

## 2. 데이터 설명

### 2.1 혼잡 데이터
- 역별·시간대별 승하차 인원을 기반으로 혼잡도를 산출
- 출근, 퇴근, 야간 등 시간대별 위험 분석에 활용

### 2.2 구조 데이터
- 승강장 이격거리 데이터를 활용하여 구조적 위험을 반영
- 이격거리가 클수록 발빠짐 사고 위험 증가 가능

### 2.3 환승 데이터
- 환승역 여부 및 환승 인원을 기반으로 이동 복잡도 반영
- 환승역은 사고 위험 설명력 증가 요인

### 2.4 사고 데이터
- 최근 5년 사고 데이터를 활용하여 모델 검증 수행
- 위험도 상위 역과 실제 사고 다발 역 비교

### 2.5 생활이동 데이터
- 역 주변으로 유입되는 외부 인구 흐름 분석
- 내부 혼잡뿐 아니라 외부 유입 압력까지 반영

### 2.6 역 위치 및 매핑 데이터
- 역 좌표 및 코드 정보를 활용하여 데이터 간 매핑 수행
- 생활이동 데이터와 지하철 데이터 결합에 활용

---

## 3. 데이터 관리 원칙

- 원본 데이터는 수정하지 않고 그대로 유지한다.
- 전처리 데이터는 `data/processed/` 폴더에서 관리한다.
- 빅데이터 캠퍼스 반출 데이터는 `data/campus_export/`에서 별도로 관리한다.
- Public GitHub에는 원본 CSV 파일을 업로드하지 않는다.
