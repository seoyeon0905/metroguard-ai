# Campus Export Data

이 폴더는 빅데이터 캠퍼스에서 반출한 데이터 및 전처리 결과를 설명하는 공간입니다.

실제 CSV 파일은 용량 및 데이터 공개 제한으로 인해 GitHub에는 업로드하지 않습니다.

---

## 2. 데이터 설명

### 2.1 반출 데이터

- 빅데이터 캠퍼스에서 제공되는 생활이동 데이터
- 특정 시간대 및 지역별 이동 인구 포함
- 역 주변 유입 압력 분석에 활용

### 2.2 공간 매핑 데이터

- 생활이동 데이터를 지하철 역 기준으로 매핑한 결과
- 셀(cell) 단위 데이터를 역 단위로 변환
- 역별 유입 인구 계산

### 2.3 통합 코드

- 여러 날짜 및 파일로 나뉘어진 데이터를 하나로 결합
- 전처리 및 집계 작업 수행
- 최종 분석 데이터 생성

---

## 3. 활용 목적

- 역 주변 외부 유입 압력 계산
- 시간대별 유입 패턴 분석
- 혼잡 데이터와 결합하여 동적 위험도 모델 구성

---

## 4. 데이터 관리 원칙

- 반출 데이터는 외부 공개가 제한됨
- GitHub에는 데이터 파일을 업로드하지 않음
- 분석 재현성을 위해 코드와 데이터 구조만 공유
