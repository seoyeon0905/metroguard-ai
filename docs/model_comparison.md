# 모델 비교 정리

## 1. 모델링 목표

본 프로젝트의 모델링 목표는 역별·시간대별 지하철 승강장 사고 발생 위험을 예측하고, 위험에 영향을 주는 주요 요인을 설명하는 것이다.

최종적으로는 모델의 예측확률을 Risk Score로 활용하여 역별·시간대별 위험도를 산출한다.

---

## 2. 메인 모델

### 2.1 XGBoost Classifier

- 타깃 변수: 사고발생 여부  
  사고발생 = 사고수 > 0

- 장점
  - 비선형 관계 반영 가능
  - 성능이 우수함
  - 변수 중요도 및 SHAP 분석으로 설명 가능
  - 공모전용 메인 모델로 가장 적합

- 활용 목적
  - 혼잡, 구조, 유입, 환승 중 어떤 요인이 사고 위험에 크게 영향을 주는지 분석
  - 예측확률을 Risk Score로 변환
  - 역별·시간대별 위험도 순위화

---

## 3. 비교 모델

### 3.1 RandomForest Classifier

- XGBoost와 비교하기 위한 baseline 모델
- 성능은 XGBoost보다 낮을 수 있으나 구조가 단순하고 설명이 쉬움
- 변수 중요도 분석 가능

### 3.2 Logistic Regression

- 해석용 baseline 모델
- “혼잡이 증가하면 사고 확률이 증가한다”와 같은 방향성 설명에 적합
- 단독 메인 모델보다는 비교용으로 활용

### 3.3 Poisson Regression / Negative Binomial

- 타깃 변수: 사고수
- 사고 “건수” 예측용
- 사고수가 대부분 0이므로 메인 모델보다는 보조 분석으로 활용

## 5. 평가지표

| 지표 | 의미 |
|---|---|
| Recall | 실제 사고 발생 데이터를 얼마나 잘 잡아내는지 평가 |
| F1-score | Precision과 Recall의 균형 |
| ROC-AUC | 전체 분류 성능 평가 |
| PR-AUC | 불균형 데이터에서의 성능 평가 |

---

## 6. 분석 흐름

1단계: XGBoost로 사고 발생 위험 예측  
2단계: SHAP 또는 변수 중요도로 위험 원인 분해  
3단계: 예측확률을 Risk Score로 사용  
4단계: 역별·시간대별 위험도 순위화  
5단계: 혼잡형 / 구조형 / 유입형 / 환승형으로 유형 분류  

---

## 7. 최종 활용 방향

본 프로젝트에서는 XGBoost Classifier를 메인 모델로 사용하여 사고 발생 위험을 예측한다.

모델의 예측확률은 역별·시간대별 Risk Score로 변환하고, 변수 중요도 또는 SHAP 분석을 통해 위험 원인을 설명한다.

이를 통해 단순히 위험도가 높은 역을 찾는 데 그치지 않고, 각 역이 왜 위험한지 분석하여 맞춤형 정책 대응 전략을 제안한다.
