# 서울시 지하철 승강장 동적 위험도 모델 아이디어 정리

## 1. 프로젝트 주제

**서울시 지하철 사고 예방을 위한 시간대별 혼잡 기반 동적 위험도 모델 구축 및 맞춤형 안전 대응 전략 제안**

본 프로젝트는 서울시 지하철 승강장 사고를 단순한 시설 문제가 아니라, **시간대별 혼잡도, 역 주변 유입 압력, 승강장 구조 위험이 결합되어 발생하는 동적 위험 문제**로 정의한다.

기존의 지하철 안전 대응은 스크린도어 설치와 같은 시설 중심의 정적 대응에 가까웠다.  
본 분석은 역별·시간대별 위험도를 정량화하고, 위험 원인을 유형화하여 실제 정책 대응에 활용 가능한 의사결정 모델을 제안하는 것을 목표로 한다.

---

## 2. 핵심 문제의식

### 2.1 기존 대응의 한계

- 기존 지하철 안전 대책은 주로 스크린도어, 시설 보수 등 정적 인프라 중심이다.
- 그러나 승강장 사고 위험은 시간대별 혼잡, 환승 흐름, 외부 유입 인구, 구조적 취약성이 함께 작용한다.
- 따라서 단순히 사고 발생 이후 대응하는 방식이 아니라, 위험이 높아지는 시간과 장소를 사전에 예측하고 대응할 필요가 있다.

### 2.2 본 프로젝트의 차별점

본 프로젝트는 다음과 같은 점에서 기존 접근과 차별화된다.

- 역 내부 혼잡도뿐 아니라 역 주변 생활이동 기반 유입 압력을 함께 반영한다.
- 승강장 이격거리, 환승 여부 등 구조적 위험 요인을 결합한다.
- 실제 사고 데이터를 활용해 위험도 모델의 현실 설명력을 검증한다.
- 단순 위험도 산출을 넘어 위험 유형 분류, 시간대 패턴 분석, 정책 우선순위 도출까지 확장한다.

## 3. 핵심 분석 흐름

```
문제 정의
→ 승강장 사고 위험을 혼잡 + 구조 + 외부 유입 압력 문제로 재정의

데이터 통합
→ 승하차 인원, 생활이동, 이격거리, 환승 여부, 사고 데이터 결합

동적 위험도 모델 구축
→ 역별·호선별·시간대별 위험도 산출

위험 유형 분류
→ 혼잡형, 구조형, 유입형, 환승형 위험역 도출

사고 데이터 기반 검증
→ 위험도 상위 역과 실제 사고 다발 역 비교

정책 의사결정 모델 제안
→ 위험 원인별 맞춤형 안전 대응 전략 제시
```

### 4.2 데이터별 의미

#### 1. 승하차 인원 데이터

역 내부의 실제 혼잡도를 설명하는 핵심 데이터이다.

- 역별 승객 수 파악
- 시간대별 혼잡도 계산
- 출근·퇴근·야간 위험 시간대 도출

#### 2. B078 생활이동 데이터

역 주변으로 몰려드는 외부 유입 압력을 설명하는 데이터이다.

단순 승하차 인원만으로는 역 주변 상권, 업무지구, 행사, 환승 수요 등으로 인해 발생하는 잠재적 혼잡을 충분히 설명하기 어렵다.  
따라서 생활이동 데이터를 활용해 역 주변으로 유입되는 인구 흐름을 함께 반영한다.

예시:

- 승하차 인원은 많지 않지만 주변 유입이 많은 역
- 평일 아침 외부 유입이 급증하는 역
- 저녁이나 주말에 상권 영향으로 유입이 높아지는 역

#### 3. 승강장 이격거리 데이터

구조적 위험을 설명하는 핵심 변수이다.

- 승강장과 열차 사이의 간격이 클수록 발빠짐 위험이 증가할 수 있다.
- 혼잡한 시간대에는 시야 확보가 어렵고 이동 압력이 커져 구조적 위험이 더 크게 작용할 수 있다.

#### 4. 환승역 정보

환승역은 사람의 이동 동선이 복잡하고, 특정 시간대에 혼잡이 집중될 가능성이 높다.

- 환승 여부
- 환승 인원
- 환승 복잡도

등을 활용해 위험도를 보완한다.

#### 5. 최근 5년 사고 데이터

모델 입력보다는 검증 및 설명용 데이터로 활용한다.

- 실제 사고 다발 역과 모델 위험도 상위 역 비교
- 발빠짐 사고와 이격거리의 관계 분석
- 시간대별 사고와 혼잡 시간대 비교

## 6. 위험도 모델 설계

### 6.1 기본 방향

단순히 혼잡, 유입, 구조 변수를 더하는 방식은 가중치의 근거가 약할 수 있다.  
따라서 사고 데이터를 활용해 변수의 영향력을 학습하거나, XGBoost와 같은 머신러닝 모델을 활용하여 위험도 점수를 산출한다.

### 6.2 초기 위험도 개념

초기 위험도는 혼잡, 유입, 구조, 환승 요인을 결합하여 다음과 같이 정의할 수 있다.

```
Risk Score = w1 × 혼잡 + w2 × 유입 + w3 × 구조 + w4 × 환승
```

여기서 각 가중치 `w1`, `w2`, `w3`, `w4`는 임의로 정하지 않는다.  
사고 데이터 기반 모델 학습 또는 변수 중요도 분석을 통해 각 요인의 영향력을 도출한다.

---

### 6.3 상호작용 기반 위험도

혼잡과 구조 위험은 단순히 독립적으로 작용하지 않는다.

예를 들어, 이격거리가 넓은 승강장이라도 사람이 적으면 사고 위험이 낮을 수 있다.  
하지만 혼잡도가 높아지면 시야가 제한되고 이동 압력이 커져 구조적 위험이 더 크게 작용할 수 있다.

따라서 다음과 같은 상호작용 구조를 고려한다.

```
Final Risk = 구조위험 × 혼잡지수² + 유입압력
```

이 식은 혼잡이 증가할수록 위험이 비선형적으로 커지는 상황을 반영하기 위한 개념식이다.

최종적으로는 사고 데이터를 활용해 회귀모델, 분류모델, XGBoost 모델을 비교하고, 가장 설명력이 높은 방식을 선택한다.

## 7. 분석 모델 후보

### 7.1 Poisson Regression

사고 건수처럼 count 형태의 데이터를 설명하는 데 적합하다.

- 사고수 예측에 활용 가능
- 변수별 영향력을 해석하기 쉬움
- 사고 건수가 적거나 0이 많은 경우 한계 존재

### 7.2 Logistic Regression

사고 발생 여부를 0/1로 변환하여 위험 발생 가능성을 예측할 수 있다.

- 사고 발생 여부 예측에 적합
- 해석이 비교적 쉬움
- 복잡한 비선형 관계를 반영하기 어려움

### 7.3 XGBoost Regressor

위험도 또는 사고수를 연속형 값으로 예측할 수 있다.

- 비선형 관계 반영 가능
- 변수 중요도 분석 가능
- 위험 점수 산출에 적합

### 7.4 XGBoost Classifier

사고 발생 여부 또는 위험 등급을 분류하는 데 활용할 수 있다.

- 고위험 여부 분류 가능
- 변수 중요도 기반 설명 가능
- 정책 우선순위 도출에 활용 가능

### 7.5 최종 방향

본 프로젝트에서는 단순 수식 기반 위험도보다, **XGBoost 기반 위험도 모델**을 중심으로 분석을 진행한다.  
이후 변수 중요도와 위험 기여도 분석을 통해 왜 특정 역과 시간대가 위험한지 설명한다.

## 8. 위험 유형 분류

위험도 점수만 제시하면 정책 대응으로 연결되기 어렵다.  
따라서 역별 위험 원인을 분석하여 유형별로 분류한다.

### 8.1 위험 유형

| 유형 | 설명 | 대응 방향 |
|---|---|---|
| 혼잡형 | 승하차 인원과 시간대 혼잡 영향이 큰 역 | 안전요원 집중 배치 |
| 구조형 | 승강장 이격거리 등 구조 위험이 큰 역 | 시설 개선, 틈 경고 강화 |
| 유입형 | 생활이동 기반 외부 유입 압력이 큰 역 | 행사·상권·출입구 주변 관리 |
| 환승형 | 환승 동선과 환승 인원이 많은 역 | 동선 분리, 안내 강화 |

### 8.2 유형 분류 방법

- 기준 기반 분류
- 클러스터링
- XGBoost 변수 중요도 기반 원인 분해

예시:

```
강남역 18시 위험 원인
- 혼잡: 65%
- 구조: 25%
- 유입: 10%

→ 혼잡형 위험역
```

## 9. 시간대별 위험 패턴 분석

동적 위험도 모델의 핵심은 위험이 고정된 것이 아니라 시간대에 따라 변한다는 점이다.

### 9.1 시간대 유형

| 유형 | 설명 |
|---|---|
| 출근형 위험역 | 오전 출근 시간대 위험 급증 |
| 퇴근형 위험역 | 오후 퇴근 시간대 위험 급증 |
| 야간형 위험역 | 늦은 저녁 또는 심야 시간대 위험 증가 |
| 주말형 위험역 | 주말 상권·관광지 영향으로 위험 증가 |

### 9.2 예시

```
신도림역
- 평일 08~09시 위험도 급증
- 환승 인원과 승하차 인원이 동시에 증가
- 출근형 + 환승형 위험역으로 분류

강남역
- 평일 18~20시 위험도 증가
- 승하차 인원과 외부 유입 압력 모두 높음
- 퇴근형 + 유입형 위험역으로 분류
```

## 10. 사고 데이터 기반 검증

### 10.1 검증 목적

모델이 산출한 위험도가 실제 사고 패턴과 얼마나 유사한지 확인한다.

### 10.2 검증 방법

1. 위험도 상위 역과 실제 사고 다발 역 비교
2. 위험도 Top 10 역 중 실제 사고 다발 역 포함 비율 확인
3. 발빠짐 사고와 승강장 이격거리의 관계 분석
4. 시간대별 사고와 혼잡 시간대의 관계 분석

### 10.3 잠재 위험역 도출

모델 위험도는 높지만 실제 사고는 아직 적은 역을 **잠재 위험역**으로 정의한다.

이는 사고가 발생한 뒤 대응하는 방식이 아니라, 사고가 발생하기 전에 선제적으로 관리할 수 있는 정책적 근거가 된다.

```
위험도 높음 + 사고 많음
→ 즉시 대응 우선 역

위험도 높음 + 사고 적음
→ 잠재 위험 역

사고 많음 + 위험도 낮음
→ 사고 원인 추가 분석 필요 역
```

## 11. 정책 의사결정 모델

### 11.1 정책 우선순위 기준

| 우선순위 | 조건 | 의미 |
|---|---|---|
| 1순위 | 위험도 높음 + 사고 많음 + 구조 위험 큼 | 즉시 개선 필요 |
| 2순위 | 위험도 높음 + 사고 적음 | 잠재 위험 관리 필요 |
| 3순위 | 사고 많음 + 구조 위험 낮음 | 운영 관리 또는 혼잡 관리 필요 |

### 11.2 맞춤형 대응 전략

| 위험 유형 | 대응 전략 |
|---|---|
| 혼잡형 | 시간대별 안전요원 집중 배치, 승객 분산 안내 |
| 구조형 | 승강장 틈 경고 강화, 시설 개선 우선 검토 |
| 환승형 | 환승 동선 분리, 안내 표지 개선 |
| 유입형 | 주변 행사·상권 시간대 대응, 출입구 관리 강화 |

### 11.3 정책 효과 시뮬레이션

정책 적용 전후의 위험도 변화를 비교한다.

예시:

```
시나리오 1: 혼잡도 10% 감소
→ 위험도 감소율 계산

시나리오 2: 구조 개선으로 이격거리 위험 감소
→ 위험도 감소율 계산

시나리오 3: 특정 시간대 안전요원 배치
→ 고위험 시간대 위험도 감소 효과 추정
이를 통해 한정된 예산과 인력을 어디에 우선 배치해야 하는지 판단할 수 있다.
```

## 12. 안전 대응 의사결정 시스템 제안

본 프로젝트의 최종 결과는 단순 분석 보고서가 아니라, 실제 정책 의사결정에 활용 가능한 시스템 형태로 제안한다.

### Subway Safety Decision System, SSDS

#### 입력

```
역명 + 호선 + 시간대

출력
1. 위험도 점수
2. 위험 등급
3. 위험 유형
4. 주요 위험 원인
5. 추천 대응 전략
6. 정책 우선순위

예시 출력
역명: 강남역
시간대: 평일 18~19시

위험도: 87점
위험 등급: 매우 높음
위험 유형: 혼잡형 + 유입형

주요 원인:
- 혼잡 기여도: 65%
- 유입 기여도: 20%
- 구조 기여도: 15%

추천 대응:
- 퇴근 시간대 안전요원 집중 배치
- 승객 분산 안내 강화
- 출입구 주변 유입 관리
```

## 13. 수상권으로 발전시키기 위한 핵심 전략

### 13.1 단순 점수 모델에서 설명 가능한 모델로 확장

단순히 위험도를 계산하는 것에서 끝나지 않고, 왜 위험한지 설명해야 한다.

```
위험도 계산
→ 위험 원인 분해
→ 유형별 대응 전략 제안
```
### 13.2 예측 요소 추가

현재 위험도 분석뿐만 아니라, 시간대별 평균 패턴을 활용해 위험 시간대를 예측한다.

예시:

```
신도림역은 평일 08~09시 위험도 급증
강남역은 평일 18~20시 위험도 급증
홍대입구역은 금요일 야간 위험도 증가
```

---

### 13.3 정책 시뮬레이션 구체화

단순히 “위험하다”는 결과에서 끝나는 것이 아니라, 정책을 적용했을 때 위험도가 얼마나 감소하는지 비교한다.

정책 시나리오 예시:

```
1. 안전요원 배치
2. 동선 분리
3. 구조 개선
4. 출입구 관리
```

분석 목표:

```
정책 적용 전 위험도
→ 정책 적용 후 위험도
→ 정책별 위험도 감소율 비교
```

---

### 13.4 시스템 형태로 제안

분석 결과를 실제 활용 가능한 의사결정 도구로 제시한다.

```
위험도 + 위험 유형 + 예측 + 정책 대응 + 우선순위
```

이 구조를 갖추면 단순 데이터 분석이 아니라, 서울시가 활용할 수 있는 정책 지원 모델로 발전할 수 있다.

## 14. 최종 한 줄 정리

> 본 프로젝트는 서울시 지하철 승강장 사고 위험을 혼잡, 생활이동 유입, 구조 위험, 환승 복잡도의 결합 문제로 정의하고, 머신러닝 기반 동적 위험도 모델을 통해 위험 시간대와 위험 원인을 설명하며, 맞춤형 안전 대응 전략과 정책 우선순위를 제안하는 의사결정 모델이다.
