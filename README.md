# 🚇 MetroGuard-AI

**AI-based Dynamic Risk Modelling for Subway Platform Safety**

서울시 지하철 승강장 사고를 예방하기 위해  
혼잡, 구조, 외부 유입 데이터를 결합한 **AI 기반 동적 위험도 모델**을 구축하고,  
맞춤형 안전 대응 전략을 제안하는 프로젝트입니다.

---

## 📌 1. 프로젝트 개요

기존 지하철 안전 대책은 스크린도어 설치와 같은 **시설 중심의 정적 대응**에 집중되어 있습니다.  
그러나 실제 사고 위험은 시간대별 혼잡, 환승 흐름, 외부 유입 인구, 승강장 구조 등  
다양한 요인이 결합되어 **동적으로 변화**합니다.

본 프로젝트는 승강장 사고 위험을 단순한 구조 문제가 아닌  
**“혼잡 + 구조 + 외부 유입 압력”의 결합 문제**로 재정의하고,  
역별·시간대별 위험도를 정량화하는 모델을 제안합니다.

---

## 🎯 2. 목표

- 지하철 승강장 사고 위험을 정량적으로 분석
- 시간대별 동적 위험도 모델 구축
- 위험 원인 설명 (Explainable AI)
- 위험 유형 분류 및 패턴 분석
- 정책 의사결정 지원 시스템 제안

---

## 🧠 3. 핵심 아이디어

```text
기존: 시설 중심, 정적 대응
→ 문제: 시간대별 위험 변화 반영 불가

개선:
혼잡 + 구조 + 외부 유입 압력
→ 동적 위험도 모델 구축
→ 위험 시간 + 위험 위치 도출
→ 정책 대응 가능
```

---

## 📊 4. 데이터 구성

### 4.1 혼잡 요인
- 지하철 호선별 역별 시간대별 승하차 인원
- 역 내부 혼잡도 계산

### 4.2 외부 유입 요인
- B078 생활이동 데이터
- 역 주변 유입 압력 분석

### 4.3 구조 요인
- 승강장 이격거리
- 환승역 여부
- 구조적 위험 반영

### 4.4 검증 데이터
- 최근 5년 지하철 사고 데이터
- 모델 결과와 실제 사고 비교

---

## ⚙️ 5. 분석 방법

### 5.1 위험도 모델

```text
Risk = f(혼잡, 유입, 구조, 환승)
```

- XGBoost 기반 사고 발생 예측
- 예측 확률을 Risk Score로 활용

---

### 5.2 모델 구성

- **Main Model**
  - XGBoost Classifier (사고 발생 여부 예측)

- **Baseline Models**
  - Logistic Regression
  - RandomForest

---

### 5.3 분석 흐름

```text
1. 데이터 전처리
2. 사고 발생 예측 (XGBoost)
3. Risk Score 산출
4. 변수 중요도 분석 (SHAP)
5. 위험 유형 분류
6. 시간대 패턴 분석
```

---

## 🔍 6. 위험도 해석 (Explainable AI)

모델의 예측 결과를 단순 점수가 아닌 **원인 기반으로 분해**합니다.

예시:

```text
강남역 (18시)
- 혼잡: 65%
- 구조: 25%
- 유입: 10%
```

👉 “왜 위험한지” 설명 가능  
👉 정책 설계에 활용 가능

---

## 🧩 7. 위험 유형 분류

| 유형 | 설명 |
|---|---|
| 혼잡형 | 승하차 인원 영향 큼 |
| 구조형 | 이격거리 등 구조 위험 큼 |
| 유입형 | 외부 유입 영향 큼 |
| 환승형 | 환승 복잡도 높음 |

---

## ⏱ 8. 시간대 패턴 분석

- 출근형 위험역
- 퇴근형 위험역
- 야간형 위험역
- 주말형 위험역

👉 위험이 언제 발생하는지 분석

---

## 🔮 9. 위험 예측

시간대별 패턴을 기반으로 위험 시간대를 예측합니다.

```text
신도림역 → 평일 08~09시 위험 급증
강남역 → 평일 18~20시 위험 급증
```

---

## 📈 10. 모델 검증

- 위험도 상위 역 vs 실제 사고 다발 역 비교
- Recall 기반 성능 평가
- 사고 유형별 상관관계 분석

---

## 🏙 11. 정책 의사결정 모델

### 11.1 우선순위 선정

| 순위 | 기준 |
|---|---|
| 1순위 | 위험도 높음 + 사고 많음 |
| 2순위 | 위험도 높음 + 사고 적음 |
| 3순위 | 사고 많지만 구조 위험 낮음 |

---

### 11.2 대응 전략

| 유형 | 대응 |
|---|---|
| 혼잡형 | 안전요원 배치 |
| 구조형 | 시설 개선 |
| 환승형 | 동선 분리 |
| 유입형 | 출입구 및 주변 관리 |

---

### 11.3 정책 시뮬레이션

```text
혼잡 10% 감소 → 위험도 감소율 분석
구조 개선 → 위험도 변화 분석
```

👉 정책 효과 정량화
