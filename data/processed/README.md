# Processed Data

이 폴더는 분석 및 모델링에 사용되는 전처리 완료 데이터를 설명하는 공간입니다.

실제 전처리 데이터셋은 용량 및 데이터 공개 범위 문제로 GitHub에 업로드하지 않습니다.

---

## 1. 주요 데이터

### df_final_all_preprocessed.csv

- 모든 변수 통합된 최종 분석 데이터
- 혼잡, 유입, 구조, 환승, 사고 데이터를 결합한 데이터

### df_final_struct_preprocessed.csv

- 구조 관련 변수 중심으로 구성된 데이터
- 승강장 이격거리 및 구조 위험 분석용

---

## 2. 데이터 구조

| 역명 | 호선 | 시간대 | 혼잡 | 유입 | 구조 | 환승 | 사고수 |
|---|---|---|---|---|---|---|---|

---

## 3. 활용 목적

- XGBoost 모델 학습
- 위험도(Risk Score) 산출
- 변수 중요도 분석
- 위험 유형 분류

---

## 4. 데이터 관리 원칙

- 원본 데이터는 `data/raw/`에서 관리
- 반출 데이터는 `data/campus_export/`에서 관리
- 전처리 데이터는 재현 가능성을 위해 코드 기반으로 생성
- Public GitHub에는 전체 데이터셋을 업로드하지 않음
