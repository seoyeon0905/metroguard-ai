# 🚇 MetroGuard-AI

## 🏆 2026 Seoul Big Data Competition Project

### AI-based Dynamic Risk Modeling and Policy Decision Support System for Subway Platform Safety

서울시 지하철 승강장 사고를 예방하기 위해  
혼잡, 구조, 생활이동 기반 유입 데이터를 결합한 **AI 기반 동적 위험도 모델**을 구축하고,  
위험 원인 해석(Explainable AI)과 맞춤형 안전 대응 전략을 제공하는 프로젝트입니다.

---

# 📌 1. 프로젝트 개요

기존 지하철 안전 대책은 스크린도어 설치와 같은 **시설 중심의 정적 대응**에 집중되어 있습니다.  
그러나 실제 사고 위험은 시간대별 혼잡, 환승 흐름, 생활이동 기반 유입, 승강장 구조 등  
다양한 요인이 결합되어 **동적으로 변화**합니다.

본 프로젝트는 승강장 사고 위험을 단순한 구조 문제가 아닌  
**“혼잡 + 구조 + 생활이동 기반 유입”의 결합 문제**로 재정의하고,  
역별·시간대별 위험도를 정량화하는 AI 기반 위험도 모델을 제안합니다.

---

# 🎯 2. 프로젝트 목표

- 지하철 승강장 사고 위험 정량 분석
- 시간대별 동적 위험도 모델 구축
- Explainable AI 기반 위험 원인 해석
- 위험 유형 분류 및 패턴 분석
- 정책 의사결정 지원 시스템 제안

---

# 🧠 3. 핵심 아이디어

```text
기존:
시설 중심의 정적 안전 대응

한계:
시간대별 위험 변화 반영 불가

개선:
혼잡 + 구조 + 생활이동 기반 유입
→ 동적 위험도 모델 구축
→ 위험 시간·위험 위치 도출
→ 정책 대응 가능
```

# 📊 4. 데이터 구성

## 4.1 혼잡 요인
- 지하철 호선별 역별 시간대별 승하차 인원
- 역 내부 혼잡도 계산

## 4.2 생활이동 기반 유입 요인
- B078 생활이동 데이터 활용
- 역 주변 외부 유입 규모 분석
- 시간대별 유입 압력 반영

## 4.3 구조 요인
- 승강장 이격거리
- 환승역 여부
- 구조적 위험 요소 반영

## 4.4 검증 데이터
- 최근 5년 지하철 사고 데이터
- 모델 결과와 실제 사고 비교 검증

- 예측 확률을 Risk Score로 활용


# 🔍 6. 위험도 해석 (Explainable AI)

본 프로젝트는 단순 위험 점수 산출을 넘어,  
SHAP(SHapley Additive exPlanations)을 활용하여  
각 변수의 위험 기여도를 해석 가능한 형태로 분석합니다.

## SHAP 분석 내용
- 변수별 위험 기여도 분석
- 변수 영향 방향성 분석
- 위험 증가·감소 요인 해석
- 주요 위험 변수 우선순위 도출

## SHAP 분석 결과 예시

```text
강남역 (18시)
- 환승: 52%
- 혼잡: 28%
- 구조: 15%
- 유입: 5%
```

👉 “왜 위험한지” 설명 가능  
👉 정책 설계 및 우선순위 선정 가능  
👉 Explainable AI 기반 안전 의사결정 지원 가능

# 🏙 11. AI 기반 정책 의사결정 지원 시스템

## 11.1 정책 우선순위 선정

| 순위 | 기준 |
|---|---|
| 1순위 | 위험도 높음 + 사고 많음 |
| 2순위 | 위험도 높음 + 사고 적음 |
| 3순위 | 사고 많지만 구조 위험 낮음 |

---

## 11.2 맞춤형 대응 전략

| 유형 | 대응 전략 |
|---|---|
| 혼잡형 | 안전요원 배치 |
| 구조형 | 시설 개선 |
| 환승형 | 환승 동선 분리 |
| 유입형 | 출입구 및 주변 관리 |

---

## 11.3 정책 시뮬레이션

```text
혼잡 10% 감소 → 위험도 감소율 분석
구조 개선 → 위험도 변화 분석
```
