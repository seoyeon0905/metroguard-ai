# Processed Data

이 폴더는 MetroGuard-AI의 분석 및 모델링에 사용되는 전처리 완료 데이터와 최종 위험도 산출 결과를 설명하는 공간입니다.

실제 원본 및 전처리 데이터셋은 용량 문제와 데이터 공개 범위 제한으로 인해 GitHub에 업로드하지 않습니다.  
대신 데이터 생성 과정은 노트북 코드로 관리하며, 최종 산출물의 구조와 활용 목적을 문서화합니다.

---

## 1. 주요 데이터

### df_final_all_preprocessed.csv

모든 변수를 통합한 최종 분석용 전처리 데이터입니다.

포함 내용:
- 역명
- 호선명
- 시간대
- 혼잡도
- 유입 인구
- 구조 위험 변수
- 환승 여부
- 사고수
- 사고 발생 여부

활용 목적:
- XGBoost 모델 학습
- 사고 발생 여부 예측
- 위험도 산출을 위한 입력 데이터 생성

---

### df_final_struct_preprocessed.csv

승강장 구조 관련 변수를 중심으로 구성한 전처리 데이터입니다.

포함 내용:
- 역명
- 호선명
- 승강장 구조 관련 변수
- 구조 위험 점수
- 사고수

활용 목적:
- 승강장 구조 위험 분석
- 구조 요인의 사고 위험 기여도 확인

---

### subway_risk_result.csv

XGBoost 기반 위험도 모델을 적용하여 산출한 최종 결과 데이터입니다.

포함 내용:
- 역명
- 호선명
- 시간대
- Risk Score
- 사고 발생 예측 확률
- 사고수
- 사고 발생 여부
- 위험 유형
- 주요 위험 원인
- 혼잡 기여도
- 유입 기여도
- 구조 기여도
- 환승 기여도
- 추천 대응 전략

활용 목적:
- 역·호선·시간대별 위험도 확인
- 위험 유형 분류
- 주요 위험 원인 해석
- 맞춤형 안전 대응 전략 제안
- 지도 시각화 및 정책 의사결정 지원

## 3. 분석 및 모델링 활용

전처리된 데이터는 다음 분석 과정에 활용됩니다.

1. XGBoost 기반 사고 위험 예측 모델 학습
2. 사고 발생 확률을 Risk Score로 변환
3. Feature Importance 기반 주요 위험 요인 분석
4. 혼잡·유입·구조·환승 요인별 기여도 산출
5. 위험 유형 분류
6. 역별 맞춤형 안전 대응 전략 제안
7. 지도 기반 위험도 시각화

---

## 4. 데이터 관리 원칙

- 원본 데이터는 `data/raw/`에서 관리합니다.
- 반출 데이터는 `data/campus_export/`에서 관리합니다.
- 전처리 데이터는 `data/processed/`에서 관리합니다.
- 최종 위험도 결과 데이터는 `subway_risk_result.csv` 형태로 산출합니다.
- Public GitHub에는 전체 원본 데이터셋을 업로드하지 않습니다.
- 데이터 재현 가능성을 위해 전처리 및 모델링 과정은 코드 기반으로 관리합니다.

---

## 5. 비고

본 프로젝트는 서울시 지하철 승강장 안전 문제를 대상으로, 단순 사고 통계가 아닌 시간대별 혼잡도, 유입 인구, 승강장 구조, 환승 요인을 결합하여 동적 위험도를 산출하는 것을 목표로 합니다.

최종 결과 데이터는 향후 지도 시각화, 정책 민감도 분석, What-if 시뮬레이션, 맞춤형 안전 대응 전략 제안에 활용됩니다.
